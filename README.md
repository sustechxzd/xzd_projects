# 机器人操作策略训练与鲁棒性评测

本仓库汇总了两个机器人操作策略训练与评测项目，覆盖 **真实单臂操作** 与 **仿真双臂协同操作** 两类场景。项目围绕模仿学习与视觉—语言—动作模型（VLA），完成了数据处理、策略训练、闭环部署、鲁棒性评测和失败案例分析。

> 本仓库主要用于成果展示，当前包含项目报告与演示视频；训练代码、数据集和模型权重未包含在仓库中。

## 项目一：基于 LeRobot 的 SO-101 真机抓取放置

https://github.com/user-attachments/assets/596e4f37-faeb-4dce-933c-1a855d3c8581

https://github.com/user-attachments/assets/e3b767e0-6741-44e6-957f-1022346ad665

该项目使用双相机观测与 SO-101 主从机械臂，在真实环境中完成方块抓取放置任务，并在统一协议下比较 ACT、SmolVLA 与 π0。

### 主要工作

- 建立遥操作采集、数据检查、模型训练、真机 rollout 和网格化评测的完整流程；
- 使用 50 条初始演示建立 baseline，并依据失败位置和颜色变化进行两轮定向补采；
- 在训练区域内、区域外扩 1 cm、蓝色方块和红色方块四类场景中统一评测；
- 分析数据覆盖范围与训练步数对策略成功率的共同影响。

### 代表性结果

| 模型 | 数据版本 / 训练步数 | Blue inside | Red inside | Blue outside 1 cm | Red outside 1 cm |
| --- | --- | ---: | ---: | ---: | ---: |
| ACT | v2 / 50k | **100%** | **100%** | **100%** | **95.8%** |
| SmolVLA | v2 / 10k | 68% | 72% | 58.3% | 41.7% |
| π0 | v3 / 15k | **100%** | **92%** | **91.7%** | **75%** |

结果表明，依据失败分布补充颜色变化与区域外位置数据，可以显著改善对应测试场景中的成功率。π0 在扩大数据覆盖并增加训练步数后，四类场景的表现均进一步提升。

## 项目二：基于 RoboTwin 2.0 的双 Piper 协同抓取

https://github.com/user-attachments/assets/9177c394-c411-4d98-9b2e-56836d9a218f

https://github.com/user-attachments/assets/73faefba-e883-49c7-b60c-50bbaebd4da2

该项目基于 RoboTwin 2.0 的 `pick_dual_bottles` 任务，使用官方双 Piper 专家轨迹训练 ACT 与 π0 LoRA，并完成 Easy 与 Hard 环境下的闭环评测。任务属于双臂并行协同抓取，不涉及物体交接。

### 主要工作

- 验证 RoboTwin 2.0 环境、双 Piper 资产与渲染链路；
- 检查并处理 50 条专家轨迹，共 4176 帧、三相机输入以及 14 维双臂状态与动作；
- 完成 ACT 10 条 / 50 条数据量消融；
- 基于 `π0_base` 完成 LoRA 后训练，并打通三相机、语言指令和 14 维联合动作链路；
- 对每个模型在 Easy 与 Hard 环境中分别执行 100 次闭环评测；
- 建立失败类型与失败阶段标注规范，分析碰撞、抓空和掉落等问题。

### 代表性结果

| 模型 | 训练设置 | Easy | Hard |
| --- | --- | ---: | ---: |
| ACT | 10 条 clean / 6k | 5% | 5% |
| ACT | 50 条 clean / 6k | 30% | 4% |
| π0 LoRA | 50 条 clean / 5k | 24% | 5% |
| π0 LoRA | 50 条 clean / 10k | **32%** | 4% |

增加 clean 数据或延长训练能够改善分布内 Easy 表现，但没有显著改善 Hard 域随机化泛化。代表性失败案例显示，两类策略的主要瓶颈都集中在接近物体阶段，包括视觉定位偏差、接近轨迹不准确、碰撞与抓空。

## 核心结论

1. **数据覆盖比单纯扩大同分布数据更关键。** SO-101 项目中的定向补采显著修复了颜色变化和位置外推缺口，而双 Piper 项目仅增加 clean 数据未能改善 Hard 泛化。
2. **训练收敛不等于闭环鲁棒。** π0 LoRA 的训练 Loss 持续下降，但 Hard 成功率没有同步提高。
3. **接近与抓取位姿是共同瓶颈。** 真机与仿真结果都表明，视觉定位、接近深度、末端轨迹精度和在线纠偏能力直接影响最终成功率。
4. **模型对比需要统一实验边界。** 不同机器人本体、训练预算、相机视角和控制接口下的结果只能作为参考，不能直接归因于某个模型或本体。
