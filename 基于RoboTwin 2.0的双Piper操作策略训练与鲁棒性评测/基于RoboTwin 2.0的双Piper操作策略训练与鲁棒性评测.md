## 一、项目概述

本项目基于RoboTwin 2\.0双臂操作仿真平台，在 `pick_dual_bottles` 任务上使用官方双Piper专家轨迹完成ACT与π0策略的训练、部署和闭环评测。项目首先使用ACT建立基线并完成10条/50条数据量消融，随后基于 `π0_base` 进行LoRA参数高效后训练，打通三相机、自然语言指令以及14维双臂状态与动作的完整链路。

任务要求左右两台Piper机械臂分别抓取一个瓶子，并将两个瓶子同时抬离桌面。该任务应准确描述为“**双臂并行协同抓取**”，不涉及物体交接，也不属于强时序协作任务。

本项目主要回答以下问题：

1. 能否使用官方开源数据跑通RoboTwin双Piper任务从数据处理到闭环评测的完整流程；

2. ACT与π0 LoRA在Easy标准环境和Hard域随机化环境中的表现有何差异；

3. 将ACT训练数据由10条增加至50条，能否同时改善分布内性能与域外泛化；

4. 将π0训练步数由5k增加至10k，能否改善Easy和Hard成功率；

5. 两类策略的主要失败阶段和工程瓶颈是什么；

6. 双Piper结果与官方Aloha\-AgileX在同一任务上的结果处于什么水平，以及该跨本体对比能够支持哪些结论。

## 二、任务与技术路线

### 2\.1 任务定义

|项目|内容|
|---|---|
|任务名称|`pick_dual_bottles`|
|机器人|双Piper|
|操作目标|左右机械臂分别抓取并抬升一个瓶子|
|协作类型|双臂并行协同抓取|
|单回合上限|400步|

选择该任务的原因：

- 必须使用左右两台机械臂共同完成；

- 操作轨迹较短，适合快速建立训练与评测闭环；

- 成功条件清晰，便于进行大规模自动评测；

- 失败可按左右臂、碰撞、抓取和抬升阶段进行分类；

- RoboTwin 2\.0官方提供Piper专家数据和ACT训练流程。

RoboTwin[官方任务页面](https://robotwin-platform.github.io/doc/tasks/pick_dual_bottles.html)报告Piper专家策略的数据生成成功率为81%。该数值表示自动生成成功专家轨迹的比例，不是ACT或π0策略的评测成功率。

## 五、正式评测设计

### 5\.1 评测环境与协议

|环境|配置|Episode数|用途|
|---|---|---|---|
|Easy|`demo_clean`|100|测试训练分布内表现|
|Hard|`demo_randomized`|100|测试场景随机化后的泛化能力|

所有模型均只使用clean数据训练。Hard数据不参与训练，也不用于选择Checkpoint。Easy与Hard均采用100次闭环仿真评测，单回合上限为400步。

### 5\.2 成功与失败判定

单次任务只有在左右两个瓶子均被正确抓取并达到规定抬升条件，且在400步内触发成功判定时，才记录为成功。

出现以下任一情况均判定失败：

- 任意一侧机械臂未抓住目标瓶；

- 瓶子被碰倒或推离有效抓取区域；

- 瓶子抓起后掉落；

- 已形成夹持但抬升高度不足；

- 策略停滞或振荡并达到400步上限。

## 六、实验结果

### 6\.1 总体成功率

|模型|训练数据与设置|Easy|Hard|Easy→Hard下降|
|---|---|---|---|---|
|ACT 6k|10条clean|5/100（5%）|5/100（5%）|0个百分点|
|ACT 6k|50条clean|30/100（30%）|4/100（4%）|26个百分点|
|π0 LoRA 5k|50条clean，全局Batch 32，8卡FSDP|24/100（24%）|5/100（5%）|19个百分点|
|π0 LoRA 10k|50条clean，全局Batch 32，8卡FSDP|**32/100（32%）**|**4/100（4%）**|28个百分点|

### 6\.2 数据量对ACT的影响

ACT从10条数据增加到50条数据后，Easy成功率由5%提升至30%，增加25个百分点，说明增加同分布示范显著改善了clean场景中的任务学习。

Hard成功率则由5%变为4%。100次评测中1次成功的差异可视为实验波动，不能解释为性能退化，也不能据此认为10条模型具有更好的Hard泛化能力。因此，增加clean数据主要提高了训练分布内拟合，并未有效解决随机化场景中的泛化问题。

### 6\.3 训练步数对π0的影响

π0从5k训练至10k后，Easy成功率由24%提升至32%，增加8个百分点；Hard由5%变为4%，基本不变。

这表明延长clean数据上的训练继续改善了分布内任务学习，但没有带来可测量的Hard泛化收益。即使训练Loss持续下降，也不能据此推断域外成功率同步提升。

### 6\.4 ACT与π0 LoRA对比

在相同50条clean数据与相同Easy/Hard评测协议下：

- ACT 6k：Easy 30%，Hard 4%；

- π0 LoRA 10k：Easy 32%，Hard 4%。

两者在Easy中仅相差2次成功，Hard结果完全相同。100次评测下，该差异不足以支持“π0显著优于ACT”的结论。准确表述应为：**π0 LoRA 10k与ACT在该任务上取得了相近的闭环成功率；π0成功打通了VLA后训练和双Piper部署链路，但未表现出更强的Hard域随机化鲁棒性。**

### 6\.5 与官方Aloha\-AgileX同任务结果的参考对比

RoboTwin 2\.0官方Benchmark统一使用双Aloha\-AgileX本体，每个单任务使用50条 `demo_clean` 专家轨迹训练，并在 `demo_clean`（Easy）和 `demo_randomized`（Hard）中各评测100次。官方论文给出的训练设置为：ACT使用chunk size 50、batch size 8训练6000个epoch，并在部署时使用时间聚合；π0使用batch size 32进行30,000步单任务微调。官方榜单中 `pick_dual_bottles` 的结果为ACT 31%/0%、π0 57%/12%。[官方Leaderboard](https://robotwin-platform.github.io/leaderboard)、[RoboTwin 2\.0论文附录](https://arxiv.org/html/2506.18088v2)

|策略|官方Aloha\-AgileX设置|官方Aloha Easy / Hard|本项目双Piper设置|双Piper Easy / Hard|双Piper相对官方差值（Easy / Hard）|
|---|---|---|---|---|---|
|ACT|50条clean，官方6000\-epoch设置|31% / 0%|50条clean，6k训练|30% / 4%|\-1 / \+4个百分点|
|π0|50条clean，batch 32，30k微调|57% / 12%|50条clean，全局batch 32，LoRA 10k|32% / 4%|\-25 / \-8个百分点|

对比结果边界解释：

1. **ACT的Easy结果基本达到官方Aloha参考水平。** 双Piper为30%，官方Aloha为31%，仅相差1次成功，说明本项目ACT的数据处理、训练和闭环部署链路已达到合理水平。双Piper Hard为4%，官方Aloha为0%，但两者只有单次100回合评测且机器人本体不同，不能据此宣称Piper ACT的Hard泛化优于官方Aloha。

2. **π0与官方结果仍有明显差距，但不是严格控制变量对比。** 双Piper 10k相较官方Aloha 30k低25个Easy百分点和8个Hard百分点；本项目训练步数仅为官方的三分之一，同时机器人运动学、相机视角、专家轨迹、归一化统计和控制接口均不同，因此差距不能简单归因于Piper本体、LoRA适配或代码实现中的某一个因素。

3. **两种本体在Hard环境中都出现显著退化。** 官方Aloha的ACT从31%降至0%、π0从57%降至12%；本项目双Piper的ACT从30%降至4%、π0从32%降至4%。这共同说明 `pick_dual_bottles` 对场景随机化较敏感。双Piper的绝对下降幅度较小并不等价于更强鲁棒性，因为其Easy起点和π0训练预算均与官方不同。

4. **92%与81%不能放入策略成功率表。** 任务页报告的Aloha 92%和Piper 81%是专家代码生成成功轨迹的比例，而不是训练后的ACT或π0闭环评测结果。[官方任务页面](https://robotwin-platform.github.io/doc/tasks/pick_dual_bottles.html)

**双Piper ACT在Easy环境中接近官方Aloha ACT的同任务结果；双Piper π0 LoRA 10k低于官方Aloha π0 30k结果，但已完成跨本体VLA训练与部署闭环。官方Aloha数据用于参考定位，不构成严格的同配置复现。**

## 七、失败模式与案例分析

### 7\.1 ACT代表性失败结果

从ACT 50条模型的Easy和Hard评测中各选取10个代表性失败案例，共20例。该组样本中：

- 碰撞类共17例，占85%；

- 20例最早均在接近物体阶段出现致命问题；

- 典型表现包括接近深度不足、夹爪碰倒瓶子、单臂抓空、策略停滞或反复调整。

ACT失败结果表明，模型的主要瓶颈不是抬升或保持阶段，而是目标定位、末端抓取位姿和接近轨迹精度。ACT的动作块在早期出现偏差后缺少及时纠正，双臂同时运动又会增加误差耦合与碰撞概率。

### 7\.2 π0 LoRA 10k代表性失败结果

从π0 LoRA 10k的Easy和Hard评测中各选取10个代表性失败案例，共20例。统计结果为：

- 碰撞类12例，占60%；

- 未抓住类7例，占35%；

- 抓起后掉落1例，占5%；

- 接近物体阶段18例，占90%；

- 夹爪闭合阶段1例，占5%；

- 抬升阶段1例，占5%。

Easy失败主要表现为单臂或双臂碰撞；Hard除碰撞外，还明显增加了单臂或双臂抓空。Easy Episode 5中，左臂已将瓶子抬离桌面，但夹持在瓶身斜面，抬升过程中发生滑移并掉落，因此应标记为“抓起后掉落 / 抬升阶段”，而不是“左臂未抓住 / 夹爪闭合阶段”。

### 7\.3 跨模型失败结论

综合两组人工案例可以得到以下定性结论：

1. 接近阶段是ACT和π0共同的主要瓶颈；

2. Easy环境中仍存在明显的接近碰撞，说明训练分布内的末端轨迹也不够稳定；

3. Hard环境进一步增加了抓空问题，反映视觉目标定位对物体位置、纹理和背景变化较敏感；

4. 当前主要问题不是训练是否收敛，而是抓取位姿预测、接近深度控制、夹持位置与在线纠偏能力；

5. ACT样本中的碰撞占85%，π0样本中的碰撞占60%，但两组均为人工挑选的20个代表性样本，不能据此宣称π0显著减少了碰撞。

## 八、综合结论

本项目完成了RoboTwin 2\.0双Piper并行抓取任务的完整工程闭环，包括环境与资产验证、官方数据检查、ACT训练与数据量消融、π0 LoRA参数高效后训练、三相机和语言条件适配、双臂闭环部署、Easy/Hard正式评测，以及成功与失败案例分析。

主要结论如下：

1. ACT能够从50条Piper clean专家轨迹中学习基本的双臂并行抓取行为，在Easy/Hard环境中分别取得30%和4%的成功率；

2. 将ACT训练数据由10条增加至50条，使Easy成功率由5%提升至30%，但Hard仍维持约4%—5%；

3. π0 LoRA 10k在Easy/Hard环境中分别取得32%和4%，与ACT 50条模型总体表现相近；

4. π0从5k训练至10k后，Easy由24%提升至32%，但Hard由5%变为4%，说明延长clean训练主要改善分布内表现；

5. 与官方Aloha同任务结果相比，双Piper ACT的Easy结果接近（30% vs 31%），双Piper π0 LoRA 10k仍低于官方Aloha π0 30k（32%/4% vs 57%/12%）；

6. 增加同分布数据或训练步数均未解决Hard泛化问题；

7. 两类策略的失败主要集中在接近阶段，核心瓶颈是视觉目标定位、抓取位姿、接近轨迹精度和在线纠偏能力。

## 九、实验限制与结果边界

- ACT 10条与50条模型分别在RTX 4090和RTX 3090上训练，硬件环境没有完全统一；

- 各组实验只使用单个训练随机种子，尚未报告多随机种子均值和方差；

- 10条数据是50条数据的子集，但没有比较不同子集选择的影响；

- 100次评测下，ACT与π0之间2个百分点的Easy差异不能解释为显著优势；

- Hard环境没有参与训练或Checkpoint选择；

- ACT和π0的失败比例均来自人工选择的代表性样本，不代表全部失败Episode的总体分布；

- 官方Benchmark采用Aloha，本项目采用双Piper；其中官方π0训练30k，而本项目π0 LoRA训练10k。跨本体结果只能用于参考定位，不能直接用于判断机器人本体或算法实现孰优孰劣；

- 当前任务是并行抓取，不代表模型已经具备交接或强时序双臂协作能力。

## 十、后续改进方向

后续优化应优先围绕Hard泛化和接近阶段的轨迹精度展开：

1. 对全部失败Episode进行统一标注，并报告完整失败分布；

2. 引入物体位置、姿态、纹理和背景随机化的专家数据或数据增强；

3. 针对碰撞、抓空、停滞和瓶身斜面夹持等困难场景补充样本；

4. 分别评估左臂、右臂和双臂联合成功率，定位单侧控制偏差；

5. 调整ACT动作块长度或时序聚合参数，提高闭环纠错能力；

6. 引入目标可达性、碰撞约束或末端轨迹约束；

7. 使用多个随机种子重复训练与评测，并报告置信区间；

8. 若目标是对齐官方π0配置，可继续训练至30k并保持相同评测协议；

9. 在完成并行抓取后，扩展到 `handover_block` 等具有强时序协作关系的双臂任务。
